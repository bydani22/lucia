# NUESTRO PEQUEÑO MUNDO ♡ — V2

1. Sube todos los archivos y carpetas a tu repositorio de GitHub.
2. Activa GitHub Pages en Settings → Pages → Deploy from branch → main → /root.
3. En `script.js`, cambia `START_DATE` por vuestra fecha.
4. En `index.html`, cambia "Dani" y "Tú".
5. Guarda las fotos en `fotos/` con estos nombres: `hero.jpg`, `album-01.jpg` hasta `album-08.jpg`, `mallorca.jpg`, `disney.jpg` y `londres.jpg`.
6. Las fotos se cargan automáticamente desde la carpeta `fotos/` y no se pueden añadir nuevas imágenes desde el navegador.
6. Puedes crear nuevos viajes copiando la carpeta `viajes/camping`.

Esta versión añade:
- pantalla de entrada animada
- corazones al mover/clicar
- animaciones de aparición al hacer scroll
- galería con filtros
- galería ampliable al clicar
- más espacios para fotos
- sección para contar vuestra historia
- viajes
- carta sorpresa
- contador de días
- música de bienvenida
